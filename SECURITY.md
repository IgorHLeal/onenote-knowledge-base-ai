# Segurança e privacidade

Antes de publicar ou compartilhar forks deste projeto, confirme que não foram incluídos:

- `.env`;
- `.token_cache.json`;
- tokens OAuth;
- credenciais;
- e-mails internos;
- `base_bruta.json` ou bases normalizadas reais;
- HTMLs extraídos do OneNote;
- artigos Word com conteúdo corporativo;
- dumps de logs que contenham dados de clientes.

Use apenas os arquivos `*.example.*` para demonstrar configuração.
